# MOND

A soothing illustrated bunny adventure for a quiet winter night.

## Play

[Play MOND](https://diamondcao1996.github.io/MOND-game/)

Jump from the balloon, explore four painted worlds, shelter from the weather, outsmart hunters, and return to a warm burrow. Each glowing question mark opens one untimed challenge. There are 12 reasoning riddles and 12 music lessons with a playable piano. Build your burrow, garden, trade, and unlock outfits.

## Controls

- **A / D** or **arrow keys**: move
- **Space**: jump; hold to glide
- **S / Down**: hide or dive
- **E**: play or distract
- **Shift**: boost
- **F**: dig on the ground
- **Q**: retry a nearby question
- **1–4**: choose a riddle answer
- **Esc / P**: pause or close a panel

Touch controls are available on phones and tablets.

## Saving

Progress saves in the current browser. The GitHub Pages version has its own save, separate from the earlier download link. Clearing browser storage removes the local save.

## Hosting and offline use

GitHub Pages publishes the root of the `main` branch. `.nojekyll` keeps the site static. No server, account, API key, or build step is needed.

`index.html` contains the complete game, including its artwork, audio, styles, and scripts. Download that file and open it in a browser to play offline. `preview.png` is the sharing image.

To release an update, replace `index.html` on `main`; GitHub Pages publishes the change automatically.
